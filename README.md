# 编程农场 · The Farmer Was Replaced 脚本合集

| 分类 | 脚本 | 作用 |

## 使用方法

1. 打开游戏内的代码编辑器
2. 复制对应 `.txt` 文件的全部内容
3. 粘贴进编辑器运行

## 常用 API 速查

| 函数 | 作用 |
| --- | --- |
| `move(North / East / South / West)` | 朝指定方向移动一格 |
| `till()` | 把当前格翻成耕地 |
| `can_harvest()` | 当前格作物是否可收（返回布尔值） |
| `harvest()` | 收割当前格 |
| `plant(Entities.X)` | 在当前格种植指定作物 |
| `get_entity_type()` | 当前格实体类型 |
| `get_ground_type()` | 当前格地面类型 |
| `get_world_size()` | 农场边长 |

## 注意事项

- **缩进问题**：部分脚本混用了 Tab 和空格（例如 `拔萝卜拔萝卜.txt` 中 `move()` 用空格、`harvest()` 用 Tab）。粘贴进游戏前建议统一成同一种，否则会报缩进错误。
- **`can_harvest()` 是查询不是动作**：单独写一行只是取值后丢弃，不会收割。要真正收获需配合判断：

  ```python
  if can_harvest():
      harvest()
  ```

- **世界边界环绕**：游戏地图是首尾相连的，`move(North)` 走满一圈会回到原点，脚本正是靠这个特性遍历。
